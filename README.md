# API Gateway

API Gateway for the PayFlow Fintech Platform.

## Features

- Spring Cloud Gateway
- Eureka Service Discovery
- Dynamic Route Management
- Centralized Entry Point
- Actuator Monitoring
- Load Balancing

## Routed Services

- Auth Service
- User Service
- Wallet Service
- Transaction Service
- Payment Service
- Notification Service

## Tech Stack

- Java 21
- Spring Boot 3
- Spring Cloud Gateway
- Eureka Discovery Client
- Maven

## Port

8088

## Architecture

Client → API Gateway → Microservices
